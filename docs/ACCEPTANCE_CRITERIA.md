# 驗收條件

> 本文件為使用者於 2026-11-11 核准的 Spike 0 驗收條件。修改需使用者核准，並記入 [DECISIONS.md](DECISIONS.md)。
> 目前狀態見 [TEST_STATUS.md](TEST_STATUS.md)，測試步驟見 [TESTING.md](TESTING.md)。

## 1. Gate（G0）

**G0-01～05 均為必要驗收。** G0-06、G0-07 為研究項目，不阻擋 MVP。

| Gate | 必須驗證 |
| --- | --- |
| G0-01 | 兩台實體 Win11 直接 IP 連線、TLS 1.3、首次 SPKI 指紋核對、自訂帳密登入、三條 TLS 連線及一次性 Token |
| G0-02 | DXGI → H.264 → 控制端顯示，並能實際操作鍵盤與滑鼠 |
| G0-03 | 登入自動啟動、鎖定暫停、本機解鎖恢復、登出中止、A→B→A 使用者切換不誤連；斷線及輸入逾時時清理遠端按鍵；安全桌面不可操作時暫停，恢復時丟棄舊輸入事件 |
| G0-04 | HwndHost 畫面區能接收鍵鼠，且能從本地 Explorer 拖入檔案與資料夾；若失敗，驗證替代渲染方案 |
| G0-05 | 遠端檔案面板可將檔案與資料夾拖到本地 Explorer；雜湊錯誤、中斷及取消有正確處理；必要時採用已驗證的本地暫存方案 |
| G0-06 | 管理員視窗操作的可行性研究，不阻擋 MVP |
| G0-07 | 精確辨識 UAC 並提示，不阻擋 MVP；但安全暫停與恢復屬於 G0-03 必要條件 |

## 2. HostGuard（GUARD）

| ID | 驗證內容 |
| --- | --- |
| GUARD-01 | 遠端按住 Ctrl 時強制終止 Host.exe，Guard 偵測結束並嘗試釋放輸入 |
| GUARD-02 | 遠端按住滑鼠左鍵拖曳時強制終止 Host.exe，清理滑鼠按住狀態 |
| GUARD-03 | Host.exe 連續崩潰，確認不會無限重啟 |
| GUARD-04 | 本機與遠端使用者同時操作修飾鍵時發生崩潰，確認是否誤干擾本機輸入，並記錄 Windows API 限制 |
| GUARD-05 | 鎖定、登出、切換使用者、正常結束工具時，不得持續注入輸入或重啟錯誤工作階段 |

HostGuard 維持同一使用者權限、不連網路的獨立小型元件。

## 3. 狀態定義

| 狀態 | 意義 |
| --- | --- |
| NOT_STARTED | 尚未開始開發或測試 |
| IN_PROGRESS | 開發中，尚未進入驗收 |
| PARTIAL_PASS | 部分條件已驗證通過，其餘尚未執行（須註明缺哪些） |
| PASS | 全部條件已在規定環境下驗證通過 |
| FAIL | 驗證未通過（保留紀錄，修正後重新驗證） |
| BLOCKED | 因外部因素無法進行（須註明原因） |

## 4. 驗收規則

1. **未執行的雙機測試不得以單機結果代替。** 條件寫「兩台實體 Win11」者，只有雙機實測通過才可標 PASS。
2. 自動測試（含 Linux 上的跨平台測試）只能作為佐證，不能取代 Windows 實機驗收。
3. **不刪除失敗測試紀錄**。FAIL 紀錄保留在 [TEST_STATUS.md](TEST_STATUS.md) 的測試紀錄中，修正後新增一筆 PASS。
4. 每個開發階段完成後，執行相關回歸測試，結果記入測試紀錄。
5. 每筆紀錄需註明：日期、commit、環境（實機 / 雲端）、執行者、結果、證據或備註。
