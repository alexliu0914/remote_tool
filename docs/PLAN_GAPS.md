## 四、需要決定的項目說明（G-02、G-06、G-08、G-09 已於 2026-11-11 核准；G-06 尚待處理）

**G-06 主機信任**：規劃書要求以公鑰識別主機。建議做法：控制端記住「已信任的公鑰清單」；連到任何位址時，只要對方公鑰在清單中就直接信任，不在清單就要求核對。代價是：某台已信任的電腦換了 IP 不會再詢問（符合規劃書）；但若同一個位址出現另一把**已信任**的公鑰（例如兩台都信任過、IP 互換），也不會警告。若要在「同一位址換成另一把金鑰」時仍警告，可再保留位址紀錄作為提示。

**G-08 封包表頭**：規劃書的 RequestId（請求 / 回應配對）與 Sequence（序號）目前沒有用到的地方，但檔案傳輸、續傳會需要。改格式會讓現有測試全部更新，越早改成本越低。

**G-09 .NET 10**：.NET 10 是 LTS，支援期比 .NET 8 長。升級需要你的電腦安裝 .NET 10 SDK（`winget install Microsoft.DotNet.SDK.10`），程式碼改動很小。
