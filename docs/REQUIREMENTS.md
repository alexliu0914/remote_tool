# 需求（MVP 範圍）

> **來源**：規劃書原文 [plan/PLAN_V2.2.2.md](plan/PLAN_V2.2.2.md)（第一、六節為主），以及使用者於對話中核准的內容。
> 本文件是原文的摘要索引；**與原文不一致時以原文為準**（D-034）。
>
> **規則**：本文件定義的 MVP 範圍**不得擴大**。新增功能需使用者核准並記入 [DECISIONS.md](DECISIONS.md)。

## 1. 產品定位

Windows 11 點對點遠端操控工具（自用）。控制端直接以 IP 連到被控端，**不經任何中央協調、雲端或中繼伺服器**。

## 2. 平台

| 項目 | 規格 |
| --- | --- |
| 控制端 | Windows 11 x64 |
| 被控端 | Windows 11 x64 |
| 執行權限 | 一般使用者權限；不使用 Windows 服務、不使用 SYSTEM |
| 執行環境 | .NET 10（LTS）（D-036） |

## 3. 功能需求（MVP）

| ID | 需求 | 對應驗收 |
| --- | --- | --- |
| R-01 | 直接以 IP 連線，三條 TLS 1.3 連線共用 TCP 52100（Control / Video / File） | G0-01 |
| R-02 | 被控端自訂帳號密碼登入，可建立一或多組帳號；同時一名控制者 | G0-01 |
| R-03 | 首次連線核對主機指紋 SHA-256(SPKI)；指紋變更即中止 | G0-01 |
| R-04 | 遠端畫面：DXGI 擷取 → H.264 編碼 → 控制端解碼顯示（硬體優先，軟體備援）；目標 1080p 30 fps | G0-02、VID-01 |
| R-05 | 遠端鍵盤與滑鼠操作 | G0-02、GUARD-01～05 |
| R-06 | 中英文輸入（遠端輸入法）與「貼上 Unicode 文字」 | HID-01 |
| R-07 | 雙向文字剪貼簿（只同步 CF_UNICODETEXT，單次 1 MB） | CLP-01 |
| R-08 | 雙向檔案與資料夾傳輸，透過工具內拖拉（本地 Explorer ↔ 遠端檔案面板） | G0-04、G0-05 |
| R-09 | 工作階段狀態處理：鎖定暫停、本機解鎖恢復、登出中止、使用者切換不誤連 | G0-03 |
| R-10 | 斷線與輸入逾時時清理遠端按鍵；安全桌面（UAC）時暫停，恢復時丟棄舊輸入 | G0-03 |
| R-11 | 多螢幕、游標、高 DPI、解析度切換 | VID-01、HID-01 |
| R-12 | 被操控提示、稽核記錄（Windows 事件記錄） | — |
| R-13 | 前景為管理員視窗時偵測並提示無法操作 | HID-02 |
| R-14 | 安裝：WiX MSI、防火牆規則（預設僅私有網路）、登入時執行的排程工作、程式碼簽章；升級保留主機金鑰與帳號 | INST-01 |

## 4. 不做（Out of scope）

- 雲端中繼、NAT 穿透協調伺服器
- 手機、Mac 控制端或被控端
- 登入前（Windows 登入畫面）連線
- 遠端操作 UAC 安全桌面
- 提升權限（以系統管理員或 SYSTEM 執行）

研究項目（不阻擋 MVP）：G0-06 管理員視窗操作的可行性、G0-07 精確辨識 UAC 並提示。

## 5. 非功能需求

| ID | 需求 |
| --- | --- |
| N-01 | 指紋核對必須在送出帳密**之前**完成 |
| N-02 | 密碼至少 10 字元，以 Argon2id 雜湊；設定與私鑰以 DPAPI（目前使用者）加密；漸進延遲 + 全域節流 + 同時連線上限，不採鎖定 |
| N-03 | 所有網路輸入一律視為不受信任：長度上限、拒絕未知類型、格式錯誤即中止 |
| N-04 | HostGuard 為同一使用者權限、**不連網路**的獨立小型元件，是唯一呼叫 SendInput 的程式 |
| N-05 | Host 異常結束時不得留下按住的鍵或滑鼠鍵；不得無限重啟 |
| N-06 | 鎖定、登出、切換使用者、正常結束時，不得持續注入輸入或重啟到錯誤的工作階段 |
| N-07 | 暫時方案（例如 A1 未壓縮畫面）必須限制解析度、FPS 與佇列大小 |
| N-08 | 效能目標（待量測，非保證）：區網輸入到畫面延遲 < 50 ms、頻寬 2–8 Mbps、被控端 CPU < 15%（有硬體編碼時） |
| N-09 | 記錄不寫密碼、Token 或剪貼簿內容；登入失敗只記來源 IP 與時間 |
